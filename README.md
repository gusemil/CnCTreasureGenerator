# Castles & Crusades Treasure Generator

A browser version of the CastlesAndCrusadesApp (https://github.com/gusemil/CastlesAndCrusadesApp) terminal treasure roller, in plain HTML, CSS and
JavaScript, ported from original C# implementation. No build step and no server: the files in this folder are the whole site.

Live at https://gusemil.github.io/cnc-treasuregenerator/

## Run locally

Open `index.html` in a browser (straight from disk works).
